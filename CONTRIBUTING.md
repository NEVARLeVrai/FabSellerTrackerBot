# 🤝 Contributing to FabSellerTrackerBot

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 

This repository is a fork of [MMadmer/EpicAssetsNotifyBot](https://github.com/MMadmer/EpicAssetsNotifyBot). Use this repository for fork-specific changes and the upstream project for general changes.

## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/NEVARLeVrai/FabSellerTrackerBot.git

## ✅ Verify your changes

Use a test Discord server and sanitized sample events to validate bot changes. Keep account credentials out of examples.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
